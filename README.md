# 🎲 TUTTO Calculator

A clean and modern point calculator for the popular card/dice game **TUTTO**. Built with React, Tailwind CSS, and shadcn/ui.

## ✨ Features

- **Easy Player Management:** Easily add and manage players before starting the game.
- **Dynamic Score Tracking:** Seamlessly input and update scores as the game progresses.
- **Live Leaderboard:** Keep track of the current standings with a real-time leaderboard showing who is in the lead.
- **Turn Log:** View the history of previous rounds to stay on top of the game data and ensure transparency.

## 🚀 Tech Stack

- **Framework:** React (TypeScript)
- **Styling:** Tailwind CSS
- **UI Components:** shadcn/ui
- **Hosting:** Vercel

## 📦 Installation & Setup

To run this project locally, follow these steps:

1. **Clone the repository:**

```bash
   git clone https://github.com/FabianEilts/tutto-calculator.git
   cd tutto-calculator
```

2. **Install dependencies:**

```bash
   npm install
```

3. **Start the development server:**

```bash
   npm run dev
```
